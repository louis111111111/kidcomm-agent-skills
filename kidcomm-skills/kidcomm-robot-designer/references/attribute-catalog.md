# 外形必填目录（Appearance Catalog）

孩子"捏脸/身体"从 0 开始、天马行空。为让技术组能建模，**必须有标准化的最小属性集**。本目录定义哪些字段必填、哪些可选。

## 必填（未完成"捏脸"不得进入性格阶段）
| 字段 | 含义 | 取值 |
|------|------|------|
| `shape` | 整体轮廓（常规形状；另设"其他"可自由填写，如恐龙、小猫） | round / square / triangle / oval / star / heart（或 其他 自由文本） |
| `color_primary` | 主体颜色 | red/blue/green/yellow/pink/purple/orange/black/white/silver/gold |
| `size` | 体量 | small / medium / large |

> 必填三件套是"能区分一个机器人长什么样"的最小信息。缺一，技术组无法建模，所以前端强制校验。文字里已说到的维度会直接确认、不再重复给选项。

## 可选
| 字段 | 含义 | 取值 |
|------|------|------|
| `parts` | 特征部件（**仅身体器官**，让"会飞的恐龙"成立的关键：选 翅膀） | 身体/头/翅膀/尾巴/触角/爪子/手臂 |
| `texture` | 质感 | 毛茸茸/金属/软胶…（抽象词"软"映射而来） |

## 抽象 → 具体 语料（agent 引导用）
孩子常说"可爱的""酷的"，需引导到具体属性。`corpus/corpus.json` 的 `abstract_to_concrete`（机器读、`design.py` 加载，单一真相源；原型内嵌镜像）内置映射：
- 可爱/萌 → 圆 + 粉
- 酷 → 黑
- 帅 → 蓝
- 凶 → 红
- 软 → 毛茸茸 + 圆
- 威风 → 大 + 翅膀

引导策略：**先识别文字、先映射**；文字里没提到的维度才在下一步给选项（已填的只做确认，可✎改）。识别抽象词→回填具体属性→追问仍缺失的必填项，直到三件套齐备。
