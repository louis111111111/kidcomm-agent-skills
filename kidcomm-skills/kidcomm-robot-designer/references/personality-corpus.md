# 性格语料映射（Personality Corpus）

捏完脸选性格。性格**用选择题**（话术引导），不用自由输入——因为性格要可映射到确定的**表情 + 动作 + 语气**，技术组才能驱动机器人。

## 六类性格映射
| 性格 | 表情 expression | 典型动作 actions | 语气 tone |
|------|----------------|-----------------|-----------|
| 开心 happy | 弯弯笑眼 + 大笑 | 蹦跳、转圈、挥手 | 轻快 |
| 愤怒 angry | 圆睁眼 + 锯齿嘴/抿紧 | 跺脚、挥拳、喷气 | 低沉大声 |
| 胆小 timid | 大睁眼 + 小嘴 | 躲身后、缩头、小碎步 | 细声 |
| 勇敢 brave | 坚定眼神 + 微笑 | 大步前进、张开双臂、保护姿态 | 稳 |
| 温柔 gentle | 柔和眼 + 浅笑 | 轻拍、拥抱、慢慢走 | 轻柔 |
| 调皮 naughty | 眨眼 + 坏笑 | 做鬼脸、偷偷动、蹦跳 | 俏皮 |

## 设计要点
- 表情 → 面部参数（眼睛曲率、嘴型），动作 → 运动序列，语气 → TTS 风格。三者都可由技术组直接编程。
- 选择题降低儿童认知负担，也保证输出"可控、可复现"（符合 NVIDIA Tier-3 评测的稳定性要求）。
- 语料可扩展：新增性格只需在 `design.py` 的 `PERSONALITY` 加一条，前端同步一个选项。

## 与"捏脸"的关系
性格是**叠加在外观之上**的层：外观决定"长什么样"，性格决定"怎么动、怎么表达"。最终设计稿把两层合并成一个 `design` 对象交给技术组。
