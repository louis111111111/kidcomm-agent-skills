# 语料与映射表（Corpus & Mapping）— kidcomm-robot-designer

> **这是本 Skill 语料/映射的权威、可交接文档。** 机器读取用同目录 `corpus.json`（`design.py` 直接加载，单一真相源）；本文件用来**向技术组/评审/接手人解释每一项目为什么这么映射**。改映射请以 `corpus.json` 为准。
> 注：独立的在线测试原型（如有）只是本地体验用，**不随 Skill 发布**；其内嵌映射亦以 `corpus.json` 为唯一真相源。

> 🔍 **可解释性（设计意图）**：引导流程在文字引导和外形确认两步应展示「我是这么理解的」面板，实时呈现**原话 / 命中的抽象词→具体属性 / 抓到的具体词 / 已填槽位 / 还缺什么**，让自然语言如何被解析、是否正确映射一目了然（映射来源标注为 `corpus.json`）。接手人可据此逐条核对。

---

## 0. 为什么需要映射（设计背景）
儿童表达天马行空、且常常**抽象**（"可爱的""酷的"），无法直接建模。本 Skill 把自然语言/草图转成技术组可执行的**标准化外形 + 性格**。映射表解决两件事：
1. **抽象 → 具体**：把"可爱的"这类词落成可填的属性（形状/颜色/大小/部件）。
2. **性格 → 行为**：把"开心/愤怒"落成可驱动的表情/动作/语气。

> ⚠️ **诚实声明**：本表目前为 **v1 由项目团队（Louis + WorkBuddy）基于常识与儿童设计直觉手工编写**，**尚未引用权威儿童发展心理学或角色设计 taxonomy**。若需评审级严谨度，应在 `corpus.json` 中补充出处字段并对照文献 grounded（见文末待办）。

---

## 1. 外形关键词词典（具体词 → 标准值）
孩子说的具体词直接命中，写入 `appearance`。

| 维度 | 中文词 → 标准值（英文） |
|------|------------------------|
| 形状 shape | 圆→round，方→square，三角→triangle，椭圆→oval，星形→star，爱心→heart；另设「其他」项可自由填写（如恐龙、小猫） |
| 颜色 color_primary | 红→red，蓝→blue，绿→green，黄→yellow，粉→pink，紫→purple，橙→orange，黑→black，白→white，银→silver，金→gold |
| 大小 size | 小→small，中→medium，大→large |
| 部件 parts（可多选） | 身体，头，翅膀，尾巴，触角，爪子，手臂（**仅身体器官**，已去掉墨镜/王冠/灯笼/螺旋桨/轮子等配件细节） |

> 规则：形状和颜色**必填**（凑齐才能完成"捏脸"）；大小**必填**；部件可选（让"会飞的恐龙"成立的关键：选 翅膀）。

---

## 2. 抽象词 → 具体属性（agent 引导用）
孩子常说抽象词。命中后**回填具体属性**，并用童声话术确认，再追问仍缺失的必填项。

| 抽象词 | 映射到的属性 | 解释（给孩子/接手人看） |
|--------|--------------|--------------------------|
| 可爱 / 萌 | shape=round，color_primary=pink | 圆圆的脸、粉粉的颜色、大大的眼睛 |
| 酷 | color_primary=black | 黑黑的、酷酷的 |
| 帅 | color_primary=blue | 蓝蓝的、帅帅的 |
| 凶 | color_primary=red | 红红的、凶凶的 |
| 软 | texture=毛茸茸，shape=round | 毛茸茸的、圆圆的 |
| 威风 | size=large，parts=[翅膀] | 大大的、带翅膀 |

> 例：孩子说"我想要一个可爱的" → 自动填 形状=圆、颜色=粉 → 再问"大小呢？"。

> 约定：`abstract_to_concrete` 里的 `shape`/`color_primary` 一律写**英文标准值**（如 `round`/`pink`），与最终 JSON 契约一致；`design.py` 与任何前端展示都同步此约定（早期版本误用中文"圆"会导致槽位高亮和导出 JSON 不一致，现已修正）。

## 3. 性格 → 表情/动作/语气（选择题用）
性格用**选择题**而非自由输入，保证输出可控、可复现（符合 NVIDIA Tier-3 稳定性要求）。每类映射到确定的三层行为：

| 性格 | 表情 expression | 典型动作 actions | 语气 tone |
|------|----------------|-----------------|-----------|
| 开心 happy | 弯弯笑眼 + 大笑 | 蹦跳、转圈、挥手 | 轻快 |
| 愤怒 angry | 圆睁眼 + 锯齿嘴/抿紧 | 跺脚、挥拳、喷气 | 低沉大声 |
| 胆小 timid | 大睁眼 + 小嘴 | 躲身后、缩头、小碎步 | 细声 |
| 勇敢 brave | 坚定眼神 + 微笑 | 大步前进、张开双臂、保护姿态 | 稳 |
| 温柔 gentle | 柔和眼 + 浅笑 | 轻拍、拥抱、慢慢走 | 轻柔 |
| 调皮 naughty | 眨眼 + 坏笑 | 做鬼脸、偷偷动、蹦跳 | 俏皮 |

> 表情 → 面部参数（眼曲率、嘴型）；动作 → 运动序列；语气 → TTS 风格。三者都可由技术组直接编程。
